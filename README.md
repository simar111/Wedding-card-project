# Royal Wedding Invitation — React + Vite + Tailwind

A premium, responsive Indian wedding invitation website featuring:
- Full-screen cinematic curtain opening intro
- Framer Motion scroll/reveal/hover animations
- Royal maroon, antique gold and ivory palette
- Indian-inspired floral/ornamental details
- Couple section, story, events, countdown, gallery, venue and RSVP CTA
- Fully responsive mobile layout
- Vite + React + Tailwind CSS v4

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
npm run preview
```

## Customize

Most content is in `src/main.jsx`.
- Change names/date/venue/events
- Replace the Unsplash image URLs with your own wedding photos
- Change colors in `src/styles.css`
- Change countdown target in `Countdown()`

No backend is required.
